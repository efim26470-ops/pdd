# Онлайн-обновление ПДД+ v6

Сайт проверяет URL манифеста из раздела «Обновления». По умолчанию используется:

`./updates/manifest.json`

Манифест может лежать в этом же GitHub Pages репозитории или на другом HTTPS-домене с разрешённым CORS.

## Формат manifest.json

```json
{
  "version": "2026.10.12.1",
  "updatedAt": "2026-10-12T12:00:00+03:00",
  "notes": "Описание обновления",
  "questions": "questions.json",
  "signs": "signs.json",
  "cars": "cars.json"
}
```

URL файлов разрешаются относительно URL самого манифеста. Можно обновлять только одну секцию, оставив остальные поля `null`.

## questions.json

JSON-массив. Минимальные поля вопроса:

```json
{
  "id": 1,
  "ticket": 1,
  "topic": "Приоритет",
  "q": "Текст вопроса",
  "answers": ["Ответ 1", "Ответ 2", "Ответ 3"],
  "correct": 1,
  "explain": "Пояснение",
  "image": "https://.../image.svg"
}
```

`correct` — индекс правильного ответа, начиная с 0.

Для вопроса по знаку можно использовать `_signId` вместо `image`.

## signs.json

```json
{
  "id": "2.1",
  "cat": "Приоритет",
  "name": "Главная дорога",
  "meaning": "Описание",
  "image": "https://...",
  "imageCandidates": ["https://...", "https://..."]
}
```

## cars.json

Минимально: `make`, `model`; интерфейс ожидает также массив `generations`.

## Как обновлять GitHub Pages

1. Разместите проверенные JSON-файлы в `updates/` или отдельном репозитории/CDN.
2. Измените `version` в `manifest.json`.
3. Пользователь нажимает «Обновить сейчас» либо приложение автоматически проверяет источник раз в сутки.
4. Данные валидируются и сохраняются локально на устройстве.
5. После перезагрузки новый банк используется интерфейсом без пересборки сайта.

Важно: приложение не подтверждает юридическую/официальную актуальность стороннего источника. Это ответственность владельца подключённого набора данных.
