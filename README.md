# ПДД+ v2 — GitHub Pages / PWA

## Внутри
- минималистичный Liquid Glass визуал;
- тёмная / светлая / системная тема;
- 40 × 20 = 800 тренировочных вопросов A/B/M;
- расширенный справочник из 170 дорожных знаков;
- внешние изображения знаков через Wikimedia Commons с fallback;
- 23 модели автомобилей и 48 поколений;
- отдельная VAG / Volkswagen Group выборка;
- выбор поколения и технические характеристики;
- ссылки на поиск обзоров YouTube, Drom и Drive2;
- PWA, service worker, локальный прогресс/ошибки/избранное.

## Важно
Среда сборки не имела веб-доступа. Поэтому банк из 800 вопросов является тренировочным и не заявлен как официальный банк ГИБДД. Актуальность формулировок ПДД на октябрь 2026 и конкретных технических характеристик не подтверждена онлайн-проверкой.

Фото автомобилей загружаются с Unsplash как визуальные автомобильные иллюстрации и не гарантируют точное совпадение модели/поколения. Изображения знаков используют шаблонные ссылки Wikimedia Commons Special:FilePath и имеют fallback по номеру.

## GitHub Pages
Загрузите содержимое архива в корень репозитория → Settings → Pages → Deploy from a branch → main / root.

## iPhone
Откройте опубликованный HTTPS-сайт в Safari → Поделиться → На экран Домой.
