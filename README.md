# ПДД+ v9 — билеты + ПДД + знаки + разметка из предоставленных PDF

## Источники внутри сборки

- `bileti-pdd-abm-pddmaster.ru-12.1.pdf` — 40 билетов × 20 вопросов;
- `docs/pravilaPDD.pdf` — правила дорожного движения;
- `docs/znaki.pdf` — дорожные знаки;
- `docs/razmetka.pdf` — дорожная разметка.

## Что добавлено в v9

- 800 вопросов и 548 исходных иллюстраций билетов;
- отдельный раздел «ПДД» с поиском по 61 странице документа;
- 298 локальных изображений дорожных знаков, извлечённых из `znaki.pdf`;
- 48 локальных изображений дорожной разметки, извлечённых из `razmetka.pdf`;
- справочник знаков больше не зависит от случайных картинок из интернета;
- справочник разметки с поиском и фильтром;
- отдельный тест по дорожной разметке;
- тесты по знакам используют изображения из предоставленного PDF;
- ссылки на исходные PDF прямо из интерфейса;
- документы, картинки и билеты включены в PWA offline cache.

## Важная дата

PDF `pravilaPDD.pdf`, `znaki.pdf` и `razmetka.pdf` содержат пометку «Последнее обновление 1 марта 2023 года». Поэтому сайт сохраняет содержание предоставленных документов и не называет эти три справочника редакцией 2026 года.

## GitHub Pages

Settings → Pages → Deploy from a branch → `main` / root.
