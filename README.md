# ПДД+

Готовый статический PWA-проект для GitHub Pages.

## Публикация на GitHub Pages

1. Создайте новый репозиторий, например `pdd-plus`.
2. Загрузите **содержимое этой папки в корень репозитория**.
3. GitHub → Settings → Pages.
4. Source: `Deploy from a branch`.
5. Branch: `main`, Folder: `/ (root)`.
6. Сохраните и откройте выданный GitHub Pages URL.

Сайт не требует npm, Node.js или сборки.

## PWA на iPhone

Откройте опубликованный HTTPS-сайт в Safari → Поделиться → «На экран Домой».
Service Worker и manifest уже включены.

## Данные

- `data/questions.js` — вопросы тренажёра.
- `data/signs.js` — дорожные знаки.
- `data/cars.js` — каталог автомобилей.

Можно расширять массивы новыми объектами без изменения интерфейса.

## Важно

В архиве находится полностью работающий движок и демо-набор данных, а не полный официальный банк экзаменационных билетов и не исчерпывающая мировая база всех автомобилей. Перед публичным запуском рекомендуется загрузить актуальные лицензированные/официальные данные и перепроверить формулировки ПДД.
