# ПДД+ v3 — GitHub Pages / PWA

Это безопасная ревизия проекта: интерфейс не выдаёт непроверенные данные за официальные или актуальные.

## Что внутри
- минималистичный Liquid Glass UI;
- тёмная / светлая / системная тема;
- 75 уникальных тренировочных вопросов A/B/M;
- тематическая практика, ошибки, избранное и статистика;
- 170 записей справочника дорожных знаков;
- 23 модели автомобилей и 47 поколений;
- фильтр VAG / Volkswagen Group;
- выбор поколения и справочные характеристики;
- ссылки на поиск обзоров YouTube, Drom и Drive2;
- PWA и локальный офлайн-кэш интерфейса;
- страница «Статус данных» с локальной проверкой целостности.

## Почему здесь не написано «полный официальный банк»
В этой сессии веб-доступ отключён. Поэтому невозможно проверить текущую редакцию ПДД РФ, действующий официальный банк экзаменационных вопросов, изменения дорожных знаков и технические данные автомобилей на 12 октября 2026 года.

Предыдущая версия искусственно раздувала тренировочный банк до 800 позиций. В v3 дубли удалены: осталось 75 уникальных тренировочных вопросов. Это намеренное исправление качества.

## Что нужно для действительно актуальной версии
Нужен онлайн-доступ к актуальному источнику ПДД/экзаменационных вопросов с законным правом использования, актуальному перечню знаков и надёжным автомобильным спецификациям. Архитектура проекта позволяет заменить файлы в `data/` без переделки интерфейса.

## GitHub Pages
Загрузите содержимое архива в корень репозитория → Settings → Pages → Deploy from a branch → main / root.

## iPhone
Safari → Поделиться → На экран Домой.
