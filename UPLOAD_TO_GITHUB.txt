ПДД+ v9.1 — загрузка через веб-интерфейс GitHub

Почему так:
GitHub web uploader ограничивает одну загрузку 100 файлами.
В этой сборке большие папки разбиты на batch-папки максимум по 80 файлов.

Рекомендуемый порядок:

1. Сначала загрузите все файлы из корня проекта, кроме папки assets.
2. Загрузите папки: data, docs, icons, updates.
3. Создайте/откройте assets/tickets и по очереди загрузите:
   batch-01 ... batch-07
4. Создайте/откройте assets/source-signs и по очереди загрузите:
   batch-01 ... batch-04
5. В assets/markings загрузите все файлы — их меньше 100.
6. После завершения проверьте, что sw.js и data/*.js загружены из этой v9.1 сборки.

Важно:
Не смешивайте data/questions.js или data/signs.js от старой v9 с assets от v9.1,
потому что пути к картинкам были изменены.

Альтернатива без лимита 100 файлов:
используйте GitHub Desktop или обычный git push — у них этого ограничения нет.
