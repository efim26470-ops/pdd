После публикации GitHub Pages:
1. Ctrl+Shift+R
2. Если PWA показывает старую версию: DevTools → Application → Service Workers → Unregister → Reload

Что проверить:
- Тренажёр → Билеты → открывается выбор 1–40
- выбранный билет: 20 вопросов + 20:00
- Экзамен: 20:00
- Марафон: без таймера
- при 00:00 тест автоматически завершается
